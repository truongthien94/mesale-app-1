# DEC-20260817-001 - Preserve the uploaded AAB and fix links server-side

- Session: `SES-20260817-001`
- Checkpoint: `CKP-20260817-001`
- Status: accepted and deployed

## Decision

Keep the uploaded Android AAB `versionCode 2`. Fix the broken `/account/delete` web fallback and Android domain association on the server, then use `/account-deletion` in the next mobile build.

## Rationale

- The current AAB is already uploaded to Google Play and does not need a new binary for a server-side route or Asset Links fix.
- Reusing the same version code in a new upload is rejected by Play; a new binary would require `versionCode 3`.
- Play App Signing verification requires the Play signing SHA-256, not the upload-key SHA-1.
