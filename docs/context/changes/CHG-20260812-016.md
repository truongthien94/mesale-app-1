## Summary

- Added the redesigned cross-platform login UI and native provider ordering.
- Added Google JWT/JWKS verification and a production-snapshot-compatible controller that returns the canonical mobile Bearer contract.
- Added fail-closed account matching, new-user referral onboarding, 2FA continuation, registration/IP controls, and duplicate-race handling.
- Hardened and named the Google identity UNIQUE migration for repeatable exact-path deployment.
- Prevented secondary Apple/Google activity-log failures from invalidating an otherwise verified native login.
- Documented server-only Apple/Google OAuth environment placeholders without adding credentials.

## Risk And Rollback

- Disable `openapi_auth_oauth_google_status` first to roll back traffic immediately.
- Retain `google_id` and its UNIQUE invariant; removing it can reintroduce duplicate provider links.
- Code can be rolled back after the flag is off, while website Google Socialite remains a separate flow.
