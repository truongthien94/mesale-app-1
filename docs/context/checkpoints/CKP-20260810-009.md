## Routing Decision

Expo Router `5.1.11` hides `href: null` screens by setting their tab item/button to null while preserving navigation. It matches layout screen names against direct children, so nested `wallet/orders` and `wallet/withdrawals` cannot be registered as top-level tabs beside `wallet/_layout.tsx`. The new `orders.tsx` and `withdraw.tsx` files are minimal aliases to the existing canonical screens; the original nested routes remain the More-sheet/deep-link targets.
