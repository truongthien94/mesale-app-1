## Implementation

- Removed the redundant Account-section headings while retaining the four compact parent cards for account information, finance, notifications, and settings.
- Kept referral-code entry collapsed and visible only when Laravel reports the account eligible inside the server-authoritative 72-hour window.
- Rebuilt daily check-in with a seven-day streak, current/claimed/locked states, server milestones, history, mutation feedback, pagination, and themed loading/error/offline/empty states.
- Rebuilt referrals with the live F1 rate, referral code copy/share, live invited/earned statistics, network and commission views, and three-step instructions. App Store and Google Play promotional cards are intentionally absent.

- Made shared async states and the wallet stack header theme-aware. The custom wallet header respects safe areas and bounds title scaling without disabling content font scaling.
- Kept both Home files clean and excluded owner artifacts, generated exports, prompt dumps, and credentials from commits.
