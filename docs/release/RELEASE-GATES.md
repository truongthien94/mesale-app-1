# Release Gates

## Both Stores

- [ ] Native functionality demonstrated; no WebView-only wrapper
- [ ] Session Bearer auth only; no personal API key in bundle
- [ ] Account deletion in app and public web resource
- [ ] Privacy Policy, Terms, Support, and review account available
- [ ] No hardcoded credential or sensitive production data
- [ ] UGC moderation/report/block/contact implemented if comments are exposed
- [ ] Financial/cashback claims are accurate and non-guaranteed

## iOS

- [ ] Sign in with Apple
- [ ] Privacy Manifest and Required Reason APIs
- [ ] Permission usage descriptions and App Privacy declarations
- [ ] AASA/universal links
- [ ] Export compliance and review metadata

## Android

- [ ] Current target API requirement verified at submission time
- [ ] Production AAB and Play App Signing
- [ ] 16 KB page-size compatibility
- [ ] Data Safety form matches actual SDK behavior
- [ ] Asset Links/App Links
- [ ] No restricted permissions without approved use case
