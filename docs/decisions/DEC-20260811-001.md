# DEC-20260811-001 - Keep the phone journey native and use an iPhone-style frame

- Session: `SES-20260811-001`
- Task: `TSK-MOB-016`
- Status: accepted for the current UI batch; release copy review required

## Context

The owner supplied an HTML prototype for a self-running purchase and cashback journey, then requested that it appear below the Home cashback form without the visible illustration heading and without the square device frame.

## Decision

Rebuild the journey as a native React Native animation, not a WebView. Keep all values hardcoded and isolated from Laravel APIs because this component demonstrates a flow and must never create links, orders, wallet entries, or cashback records. Present it inside an iPhone Pro Max-style rounded titanium frame with a pill-shaped Dynamic Island.

## Trade-off

Removing the visible illustration label improves the requested visual composition but makes hardcoded order and cashback amounts easier to mistake for real member data or guaranteed earnings. The release team must review the surrounding copy/disclosure against App Store and Google Play misleading-claims rules before submission.

## Reversal

The frame and disclosure can be changed entirely within `PhoneFlowDemo.tsx`; no backend, route, database, or account data change is required.
