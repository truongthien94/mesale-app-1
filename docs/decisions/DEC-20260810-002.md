# DEC-20260810-002 - Defer Breaking Expo Dependency Remediation

- Date: 2026-08-10
- Session: `SES-20260810-001`
- Status: accepted for Round 4

## Decision

Do not change the mobile package graph in Round 4. Reject `npm audit fix --force`, the suggested React Native 0.72.17 downgrade, and unsupported transitive overrides. Upgrade incrementally through Expo SDK 54, 55, 56, and 57 in separate verified checkpoints.

## Rationale

The current 22 findings cannot be reduced by npm's non-force dry run. Supported remediation crosses Expo SDK and React Native compatibility boundaries. Expo's official guidance recommends one SDK at a time, and the app contains native Google/Apple authentication, SecureStore, Router, privacy configuration, and financial flows that require clean native builds and device verification at every boundary.

## Consequences

- `BLK-DEP-001` remains open and the audit count remains `7 high` / `15 moderate`.
- The target is Expo SDK 57 / React Native 0.86.2, but SDK 54 is the first checkpoint because it moves Android to API 36.
- Residual upstream advisories must be re-evaluated after every stage rather than assumed resolved by the SDK number alone.
