# DEC-20260811-003 - Display missing pending cashback as zero on Home

- Session: `SES-20260811-004`
- Task: `TSK-MOB-019`
- Status: accepted by product owner
- Supersedes: `DEC-20260811-002` display behavior only

## Context

The owner reviewed the rolling-deploy unavailable marker and explicitly required the pending card to display `0đ` instead of `--` when the production account response omits `pending_cashback`.

## Decision

Keep the API parser nullable, but convert null to zero only in the Home account-money presentation formatter. When Laravel supplies an integer amount, the real server value remains authoritative and is displayed normally.

## Trade-off

Before the backend field is deployed, zero is a visual fallback and may not represent the member's actual pending total. This is an explicit product decision and does not move financial calculation into React Native.

## Reversal

Change the pure Home formatter fallback without modifying the API contract or Laravel financial logic.
