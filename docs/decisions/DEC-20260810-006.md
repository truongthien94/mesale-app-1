# DEC-20260810-006 - Use the observed live homepage snapshot for Round C

- Session: `SES-20260810-005`
- Task: `TSK-MOB-015`
- Status: Accepted for this round; follow-up required

## Context

The homepage Page Builder is database-backed and has no public mobile JSON endpoint. The local MariaDB instance was unavailable, while the production homepage rendered a current snapshot.

## Decision

Use the observed production snapshot (`coupons -> timeline -> blog`) in the native Home tab. Do not add an endpoint, call the database, invent records, or use WebView. Keep coupon/blog records isolated so a future API-backed implementation can replace them.

## Trade-off

Coupon codes, expiry text, view counts, thumbnails, and article copy can become stale when website administrators change the Page Builder or records. `BLK-HOME-001` remains open until a reviewed mobile content contract exists.

## Reversal

Replace the static arrays with a versioned, authenticated API contract after staging/security review; no navigation or top-of-home tool changes are required.
