# DEC-20260815-006 - Bind Google Login to the Play Signing Identity

- Date: 2026-08-15
- Session: `SES-20260815-006`
- Checkpoint: `CKP-20260815-006`
- Status: accepted for Android release verification

## Decision

- Keep the public Google Web OAuth client ID in the native app so Google Sign-In can mint an ID token for Laravel.
- Do not embed the Android OAuth client ID in the JavaScript bundle.
- Register Android OAuth clients in Google Cloud by package name and certificate SHA-1, including the Play App Signing certificate for builds installed from Google Play.
- Treat a real sign-in from Internal Testing as the final end-to-end proof before production rollout.

## Rationale

- Google Play signs distributed APK splits with the Play App Signing key, not the upload key used to sign the AAB.
- Debug, upload, and Play signing certificates are distinct identities and serve different installation paths.
- The current AAB proves the source, native SDK integration, Web client, and Laravel exchange path, but it cannot prove a Google Cloud Console record that is external to the repository.
