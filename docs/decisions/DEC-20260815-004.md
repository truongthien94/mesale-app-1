# DEC-20260815-004 - Debug-Sign the Internal Standalone APK

- Date: 2026-08-15
- Session: `SES-20260815-004`
- Checkpoint: `CKP-20260815-004`
- Status: accepted

## Decision

- Build the internal APK as a release variant restricted to `arm64-v8a`.
- Sign it with the local Android debug keystore, not the Google Play upload keystore.
- Keep the APK outside Git and label it as an internal test artifact.

## Rationale

- A release variant bundles JavaScript/assets and runs without Metro on a physical phone.
- Debug signing avoids unnecessary use of the production upload key and matches prior internal APK practice.
- A single ARM64 ABI keeps the direct-install artifact compact while supporting current physical Android devices.
