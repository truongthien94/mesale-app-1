# DEC-20260811-005 - Make Account a primary tab and retire the More sheet

- Session: `SES-20260811-009`
- Task: `TSK-MOB-024`
- Status: accepted implementation decision

## Context

The owner-approved Account reference is a complete member hub, while the existing `Thêm` tab only opened a transient More sheet. Important profile, wallet, payout, referral, security, legal, theme, and logout actions need a stable native destination.

## Decision

- Replace the visible `Thêm` tab with a real `Tài khoản` tab.
- Keep the legacy More route hidden instead of exposing a second competing navigation surface.
- Build Account from existing Laravel APIs and native routes; do not duplicate wallet, bank, withdrawal, or referral data locally.
- Keep legal/support destinations on verified HTTPS resources.
- Preserve both light and dark native themes.

## Consequences

Member settings and financial destinations become directly reachable and more closely match the approved reference. The transient More-sheet interaction is removed from primary navigation; restoring it later would require a deliberate navigation decision.

## Release Constraint

Emulator and automated evidence do not complete physical-device, signed-artifact, accessibility, privacy declaration, or store-review gates.
